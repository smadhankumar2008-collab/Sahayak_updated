⚙️ How It Works

Language Lock flow: Selected → RAG → LLM → TTS same language

1

🌐 Select Language

User selects தமிழ் from dropdown. selectedLanguage = ta stored as single source of truth.

2

🎤 Ask via Voice/Text

STT uses ta-IN, question sent with language: ta in JSON. Backend trusts request.language, not auto-detect.

3

🔍 RAG Retrieval

Hybrid search with language boost 3.0 exact, topic boost 2.0, keyword→id +3.0. Retrieves Tamil docs top.

4

🤖 LLM + Validation

Strict prompt "MUST respond in Tamil ONLY". Validation is_response_in_selected_language, retry if fails.

5

🔊 TTS Same Language

ttsLanguage = selectedLanguage = ta → ta-IN voice, autoSpeak, badge 🇮🇳 தமிழ், citations.
